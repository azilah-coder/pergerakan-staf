# Papan Pergerakan Staf JTMK

Papan digital yang menggantikan papan putih di Jabatan Teknologi Maklumat & Komunikasi (JTMK), Politeknik Balik Pulau. Ia menunjukkan siapa **ada** di pejabat, siapa **HBH**, dan siapa **tiada** (kursus, bengkel, mesyuarat luar, cuti…).

- Staf log masuk dengan emel dan kod OTP (tiada kata laluan).
- Status Isnin, Rabu dan Jumaat (di pejabat) serta Selasa dan Khamis (HBH) dijana secara automatik.
- Staf kemas kini status sendiri; admin boleh kemas kini status semua staf.
- Status turut ditulis ke Google Sheet **PERGERAKAN STAFF**, satu tab bagi setiap bulan.
- App boleh dipasang di telefon (PWA).

Panduan pasang dan deploy ada dalam [docs/PANDUAN.md](docs/PANDUAN.md).
